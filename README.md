***

**ae2ores** is a simple mod that adds back the [Applied Energistics 2](https://www.curseforge.com/minecraft/mc-mods/applied-energistics-2) ores to newer versions. It only adds back the Certus Quartz Ore and Deepslate Certus Quartz Ore.

All textures used are original assets from Applied Energistics 2.
